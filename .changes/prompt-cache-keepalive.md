- When a session goes idle after a reply, Prime Agent pings the prompt cache once with 1-hour retention, so a user who returns within the hour reads the cache instead of rewriting it. It applies to models that bill cache writes and read at most 10% of the input price, for prompts of 20k tokens or more. Turn it off with **Prompt cache keepalive** in `/settings` → **Models** (global `promptCacheKeepalive`).
